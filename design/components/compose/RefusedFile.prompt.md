A file the surface turned away, answered where it was offered.

```jsx
<RefusedFile src="clip.jpg" video message="That video is too big — a post's video can be up to 100 MB."/>
<RefusedFile message="That file isn't a picture or a video CoGra can read."/>
```

**Never a dialog, never a snackbar.** The author is looking at the pick step; the answer belongs on it, listed under the tray that took the rest.

**Remove it is the only way out.** Retrying cannot make a file smaller or a format readable, so no Retry is offered — a control that would fail the same way twice is worse than none. That is the whole difference between this and an upload that failed on the network.

**One file, one line, the nearest reason** (jakob 2026-09-03). A file is judged on its own — size, then format — before it is judged against the body it wants to join, so an oversized clip is refused by its cap and not by the mixed-kind rule it also breaks.

**Omit `src` for a file nothing can read.** It has no preview, and an empty tile is the honest picture of a file the surface could not open. Do not substitute a placeholder glyph.
