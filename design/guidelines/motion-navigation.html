A dismissal exits the edge it entered from. A sheet came up, so it goes down; a dialog faded in place, so it fades. Nothing is dismissed sideways — sideways means "another screen at the same level", and a sheet is not one.

Nothing inside an arriving screen animates. No list entrance, no staggered cards: the screen arrives whole. One transition is on screen at a time.
