# ProfileStances · `spec:design:behavior-profile-stances`

ALWAYS the opinions page is titled with the person's handle and Opinions

ALWAYS the two directions stand on two tabs named in words, and never in one merged list

ALWAYS the tabs read On them and By them GIVEN the page is another person's

ALWAYS each row is a person with the public opinion the row is about, its face leading and its pair in the reader's reading mode

ALWAYS a row's opinion is read-only, and no row carries a control that changes it

ALWAYS the rows stand strongest first, by the for-or-against value, down past nothing into the ones held against

WHEN tap the On them tab -> the people holding an opinion on this person stand in the list

WHEN tap the By them tab -> the people this person holds an opinion on stand in the list

WHEN tap a row -> that person's profile opens AND its back arrow reads Back to the opinions

WHEN tap the back arrow -> the profile whose figures were tapped comes back, in the state it was left

ALWAYS the back arrow reads Back to the profile GIVEN the page was opened from another's profile

ALWAYS the back arrow reads Back to your profile GIVEN the page was opened from the reader's own profile

ALWAYS the bottom bar keeps lit the slot of the root the profile was opened from, Feed from the feed

WHEN pull down GIVEN the page stands all the way at its top -> the page refreshes AND the platform's own refresh indicator shows
