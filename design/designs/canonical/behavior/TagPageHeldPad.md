# TagPageHeldPad · `spec:design:behavior-tag-page-held-pad`

ALWAYS the topic's pad field runs Dislike to Like and Far away to Close to me

ALWAYS the topic's pad asks How much you like it and How close you want to be on its sliders, its typed fields and every spoken readout

ALWAYS the topic's pad wears the stance's twenty faces

ALWAYS the topic's pad carries Disconnect GIVEN the topic is held

ALWAYS the topic's pad carries no Disconnect GIVEN the topic is not held

WHEN drag on the pad field -> the pick is set AND the landing line reads what it would come to

WHEN tap the pad field without dragging -> NEVER the pick moves

WHEN tap Disconnect -> the dialog opens titled Disconnect from #saltmaps? AND NEVER the dialog carries a pick line

WHEN tap Cancel -> the pad closes AND nothing is staged AND the topic stays held exactly as it was

WHEN tap Set GIVEN the pick nets the held bundle to (0, 0) -> the disconnect dialog opens with its cost AND NEVER the pick is refused

WHEN tap Set GIVEN the signing goes through -> the Affinity joins the bundle AND the pad closes onto the tag page

WHEN tap Set GIVEN the signing does not go through -> the pad stays open at the pick AND the fault stands above the commit row AND Retry takes Set's place

WHEN tap Set GIVEN the write rule refuses -> nothing is staged or spent AND the notice stands where the landing line and Set were, with Not now

ALWAYS the words Walk it back, severed and severance appear nowhere on the topic's pad

ALWAYS a parked pad over the tag page takes no bottom-bar inset
