# VerifiedApp · `spec:design:behavior-verified-app`

WHEN the verification mail's link is opened where App Links hand the URL to the app -> VerifiedApp opens AND the email is verified, the link being the proof

ALWAYS the screen carries no field, and never asks for the link's secret to be pasted by hand

ALWAYS the screen carries no header and no back arrow

ALWAYS the mark, the heading and the line stand centred, and Go to the feed is a text button, the one way on

WHEN press Go to the feed GIVEN the application is still running -> ApplicantFeed opens with the task cards still left

WHEN press Go to the feed GIVEN the account is already a member -> Feed opens

ALWAYS the page scrolls when its content outgrows the screen at any width or text size, so its action stays within reach
