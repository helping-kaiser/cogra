# ComposeSensitive · `spec:design:behavior-compose-sensitive`

ALWAYS the seal beneath the sheet stays inert while the sheet is up

WHEN turn the switch on -> the mark is staged to veil the post's body and description AND the title and the tags stay readable

WHEN type in Why? -> the reason is staged to be shown on the veil

WHEN press Done GIVEN Why? is empty -> NEVER Done refuses

WHEN the reason runs past the line it has -> Why? takes one more line AND the sheet grows with it

WHEN the growing sheet meets the ceiling -> Why? scrolls inside itself AND NEVER the Done row leaves reach

WHEN the sheet cannot fit its furniture -> the grab area and the Done row stay pinned AND what stands between them scrolls AND NEVER a part of the sheet is shed

ALWAYS no count stands under Why? GIVEN more than 20 of its 140 characters remain

WHEN typing leaves 20 or fewer of Why?'s 140 characters -> the remaining count stands at the end of its supporting row reading N left

WHEN typing passes Why?'s 140 characters -> the count reads N over in the error colour AND the line A reason is at most 140 characters. takes the hint's place AND Done stays visible and goes inert AND NEVER Done hides AND NEVER a dialog opens

WHEN press Done -> the sheet closes AND the seal's Sensitive row reads the mark

WHEN tap the scrim -> the sheet closes
