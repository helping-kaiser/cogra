# ComposeTags · `spec:design:behavior-compose-tags`

ALWAYS the seal beneath the sheet stays inert while the sheet is up

ALWAYS the sheet lists every staged tag, as many as the seal's Tags row counts

ALWAYS the sheet offers no way to add a tag

WHEN tap a tag's remove control -> the tag leaves the post AND the Tags row behind the sheet counts one fewer AND NEVER a dialog asks

WHEN tap a tag's name -> the tag's pair opens in a sheet

WHEN press Done -> the sheet closes to the seal it opened from

WHEN tap the scrim -> the sheet closes to the seal it opened from
