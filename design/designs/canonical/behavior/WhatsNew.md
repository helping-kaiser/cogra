# WhatsNew · `spec:design:behavior-whats-new`

ALWAYS What's new lists whole releases, newest first, one card each, with Newest first. under the list

ALWAYS each release's dateline reads Version, the version, and its date

ALWAYS the version running here carries installed in its dateline, and it is the version the settings row reads

ALWAYS every other release's dateline carries no word

ALWAYS no release is ever drawn as a difference from the one before

ALWAYS every release's card ends in See it on GitHub, named See version and its version on GitHub for a listener

WHEN tap See it on GitHub -> that release's public page opens outside the app, its full notes and its code AND NEVER the download opens

ALWAYS no newer-version line stands GIVEN the version running here is the newest release

ALWAYS no dateline carries installed and no newer-version line stands GIVEN the version running here is not in the release registry

ALWAYS What's new carries no bottom bar and keeps its back arrow

WHEN press the header back arrow -> settings returns at its About group
