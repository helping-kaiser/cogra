# CoGra Web · `guide:web:readme`

The web frontend. See
[docs/implementation/web.md](../docs/implementation/web.md) for the
design and [web/CLAUDE.md](CLAUDE.md) for the assistant rules.

## First-time setup

Node LTS is pinned in `.nvmrc`; with [nvm](https://github.com/nvm-sh/nvm):

```bash
nvm install    # reads .nvmrc
npm ci
```

## Build, test, run

```bash
npm run dev       # dev server on https://localhost:3000 (or: make web-dev)
npm run codegen   # regenerate GraphQL types from ../schema.graphql
npm run lint      # eslint
npm test          # vitest
npm run build     # production build
```

`make web-ci` from the repo root runs the full CI sequence locally.

The dev server serves https from a self-signed certificate (`next dev
--experimental-https`, generated on first start into `certificates/`,
gitignored) and listens on every interface, so a phone reaches it at the
machine's LAN address in the secure context WebCrypto needs — see
[development.md "Reaching the web dev server from the phone"](../docs/implementation/development.md#reaching-the-web-dev-server-from-the-phone).
`make web-apk` from the repo root stages the Android debug APK into
`public/downloads/` (gitignored), which is what the login page's download
link serves.

Typed GraphQL operations are generated by GraphQL Code Generator from
the repo-root `../schema.graphql` (the checked-in backend contract)
into `src/__generated__/` — gitignored, never hand-edited.

## Pointing the app at a backend

Start the backend with `make dev` from the repo root. Server-side
requests target `GRAPHQL_URL` (default
`http://localhost:8080/graphql`); set it in `web/.env.local`
(gitignored) to point elsewhere.
